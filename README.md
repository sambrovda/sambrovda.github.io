# sambrovda.github.io

Personal hub for **Sam Brovda** (Samuel Brovda).

Published URL after GitHub Pages is enabled: https://sambrovda.github.io/

## Setup

1. Create a public repository named `sambrovda/sambrovda.github.io`.
2. Push the files in this folder to the default branch (`main`).
3. In the repo **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Wait a minute and open https://sambrovda.github.io/
